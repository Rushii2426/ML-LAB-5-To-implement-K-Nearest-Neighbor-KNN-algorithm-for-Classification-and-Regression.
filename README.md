# ML-LAB-5-To-implement-K-Nearest-Neighbor-KNN-algorithm-for-Classification-and-Regression.

This repository contains the Machine Learning Laboratory Practical 5, which focuses on implementing the K-Nearest Neighbours (KNN) algorithm for classification and regression. The practical demonstrates the application of KNN using the Pima Indians Diabetes Dataset to predict whether a person has diabetes based on various medical attributes, including glucose level, blood pressure, BMI, age, and number of pregnancies.

**Objectives:**

The main objective of this practical is to understand the working principle of the K-Nearest Neighbours algorithm and learn how it can be applied to classification problems. The experiment also focuses on data preprocessing, feature scaling, model training, performance evaluation, and hyperparameter optimization.

**Topics Covered:**

Dataset Exploration: Loading and examining the diabetes dataset using Pandas and understanding the available features.

Data Visualization: Using Matplotlib and Seaborn to create heatmaps, correlation plots, box plots, and pair plots for better understanding of the dataset.

Data Preprocessing: Identifying invalid zero values in selected medical attributes, converting them into missing values, and replacing them using median imputation.

Feature Scaling: Applying StandardScaler to standardize the numerical features and ensure balanced distance calculations.

Model Implementation: Training and testing the KNN classification algorithm using the processed dataset.

Model Evaluation: Measuring performance using accuracy, precision, recall, F1-score, and a confusion matrix.

Hyperparameter Tuning: Using cross-validation and GridSearchCV to identify suitable parameter combinations, including the number of neighbours, distance metric, and weighting method.

**Tools and Technologies Used:**

This practical uses Python as the programming language, along with Pandas and NumPy for data handling, Matplotlib and Seaborn for visualization, and Scikit-learn for preprocessing, model implementation, evaluation, and hyperparameter tuning. Jupyter Notebook is used as the development environment.

**Conclusion:**

This experiment provides practical knowledge of implementing the K-Nearest Neighbours algorithm for diabetes classification. It demonstrates the importance of data cleaning, feature scaling, appropriate selection of K, and model evaluation. Cross-validation and GridSearchCV help in identifying suitable model parameters and improving the evaluation process. Overall, this practical provides a clear understanding of the complete machine learning workflow, from dataset preparation to model performance assessment.
